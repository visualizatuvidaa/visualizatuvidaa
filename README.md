## 1. REBEL · Featured project / Proyecto principal

A browser-based rehearsal studio with a metronome, drum sequencer, songwriting and recording tools. The FlyYA text coach uses a Cloudflare Worker to connect to OpenAI.

Estudio de ensayo en el navegador con metrónomo, secuenciador de batería, composición y grabación. El tutor de texto FlyYA se conecta a OpenAI mediante un Worker de Cloudflare.

[Open REBEL / Abrir REBEL](https://bold-rain-cc1a.thaguanstudio.workers.dev/)

## 3. René Brand Match

A bilingual platform concept connecting brands with user-generated content creators. It includes separate entry points for brands and creators. AI-assisted recommendations for potential collaborations are a proposed feature.

Propuesta de plataforma bilingüe que conecta marcas con creadores de contenido UGC, con flujos separados para ambos. Las recomendaciones de colaboraciones con IA son una función propuesta.
